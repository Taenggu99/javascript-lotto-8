# 🎯 javascript-lotto-precourse

---

## ✅ 실행 흐름 (최종)

1. 구입 금액 입력
2. 금액 유효성 검사 (1000원 단위)
3. 구매 장수 계산
4. 로또 번호 생성 (1~45 중복 없는 6개)
5. 발행된 로또 번호 출력
6. 당첨 번호 입력 (숫자 6개)
7. 당첨 번호 유효성 검사
8. 보너스 번호 입력
9. 보너스 번호 유효성 검사
10. 사용자 로또 번호 비교 → 일치 개수 판단
11. 보너스 포함 등수 판별
12. 당첨 통계 출력
13. 수익률 계산 및 출력

## 📌 요구사항 체크

- ✅ 입력값 검증 시 Error 발생 + [ERROR] 메시지 출력
- ✅ 1~45 범위 숫자만 허용
- ✅ 중복 불가
- ✅ 랜덤 6개 번호 정렬 출력
- ✅ Jest 테스트 작성
- ✅ 들여쓰기 depth 2 이내 유지
- ✅ 메서드 15줄 이하 유지
